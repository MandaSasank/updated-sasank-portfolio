# Personal Portfolio Website

A responsive personal portfolio website built using **HTML, CSS, and JavaScript** to showcase my profile, technical skills, projects, and contact information.

**Live Demo:** https://mandasasank.github.io/updated-sasank-portfolio/

## Overview

This portfolio introduces me as a B.Tech Computer Science and Engineering student aspiring to build a career in the software industry. It highlights my technical skills, project experience, and interest in software and web development.

## Features

- Responsive and modern user interface
- Home, About, Skills, Projects, and Contact sections
- Animated introduction text
- Profile photo and social media links
- Dark-themed design with blue gradient accents
- Downloadable CV
- Interactive navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages for hosting

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/MandaSasank/updated-sasank-portfolio.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.
